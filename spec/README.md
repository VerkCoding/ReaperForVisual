# `.rfv.json` format

The file ReaperForVisual keeps beside a project (`<project>.rfv.json`): which tracks to show, display-only groups, role overrides and section settings, keyed by track GUID.

This folder is under the MIT licence (see [LICENSE](LICENSE)), unlike the rest of the repository, so any tool may read and write the format.

Specification: [rfv-json.md](rfv-json.md) (version 0).
